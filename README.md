# SaMu Lab

Ultra-fast, local, OpenAI-compatible text-generation server for Linux (Compose Desktop).

## Quick Start (Zero Terminal Setup)
1. Download and install the `.deb` package from GitHub Actions Artifacts.
2. Open **SaMu Lab** from your Applications menu.
3. Click **+** to pick any `.gguf` model from your storage.
4. Click **Start Server** and copy your API URL & Model Name to connect from any device on your network.
